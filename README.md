## 📖 About

**Renaissance** is a public learning journal: every weekend from September 2026 to September 2028, split between **Informatique & Electronics** (Saturday) and **Mathematics & Languages** (Sunday), rebuilding the full French academic ladder — **Terminale → Licence/CPGE (L1–L3) → Master (M1–M2, Bac+5)** — while shipping real projects along the way.

The name is deliberate. Computer science sits at the crossroads of **mathematics** (the science it's built from) and **electronics** (the hardware it runs on) — this repo treats both as first-class citizens, alongside the applied ML/DS/software-engineering work and the **three languages** (English, Spanish, German) needed for the target role: **AI/DS Engineer at Airbus, Toulouse.**

Every topic in this repo is tagged with the official French level it corresponds to (`Terminale` → `L1` → `L2` → `L3` → `M1` → `M2`), so progress is always traceable against a real academic benchmark, not an arbitrary one.
