## About the Program

This repository tracks a two-year self-study program built to close a real gap: several years into a computer science engineering degree, core fundamentals in mathematics, physics, and hands-on coding had never been properly built, in part because AI tools had been doing the work instead of me. This program rebuilds that foundation from the ground up — starting from a real diagnostic rather than an assumption — while also going beyond it into full engineering-level mathematics, general computer science, electronics, and applied AI/Data Science, with the aim of working as an AI/Data Science engineer in an engineering-intensive industry (aerospace, defense, or technology).

| Item | Details |
|---|---|
| Type | Personal self-study program |
| Fields | Mathematics, Computer Science, Electronics, Languages |
| Level | Terminale → Bac+5 (engineering level) |
| Duration | September 2026 – September 2028 |
| Context | Run in parallel with a CS engineering degree (Data Science & AI major) |
| Rhythm | Weekends — Saturday: Informatique & Electronics · Sunday: Mathematics & Languages |

## Objectives

- Rebuild real mathematical foundations, from Terminale through engineering level, verified by diagnostics rather than assumed
- Write code independently, without AI assistance, across general computer science and applied AI/DS
- Gain a working knowledge of electronics and computer architecture
- Reach a strong operational level in English, with working knowledge of Spanish and German
- Build a small portfolio of real, defensible projects
- Obtain a coherent set of recognized certifications

## Skills Targeted

- Python, SQL, and standard data/ML tooling
- Core mathematics: analysis, algebra, probability & statistics, discrete mathematics, numerical methods, optimization
- General computer science: algorithms & data structures, operating systems, networks, databases, distributed systems, security, system design
- Applied AI/DS: classical machine learning, deep learning, NLP, generative AI, MLOps
- Rigorous, self-directed study habits and clear technical documentation

## Areas Covered

| Domain | Content |
